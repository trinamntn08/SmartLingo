# 0021 Everyday French and slang reference

Date 2026-11-24. Accepted for the learner preview. French content and generated scenes await owner review.

The Slang tab serves as a reference learners can browse by situation or search in French or English. The catalogue has 287 expressions across 12 categories. Each includes an original bilingual example, a usage note and an informal, slang or vulgar label. Verlan notes name the source words. Text shorthand carries a visible label and an explanation of how people use it in writing or speech.

The reference catalogue lives in the content package alongside the course. It has its own stable IDs and no lesson completion events. Saving an expression uses the existing notebook, with shared source IDs for the two matching course senses. Spoken expressions use the existing French audio controls. Text abbreviations stay labelled in the notebook.

Thirteen photographs were generated for SmartLingo on 2026-11-24. One shows a conversation on a café terrace. Twelve represent everyday situations and are reused on cards in their category. The photos have no external source and are included as optimized JPEGs in the offline export.
