# Inline Japanese pronunciation

Accepted 2026-11-22.

Display romaji alongside Japanese vocabulary in the library, lessons, daily courses and notebook. Show the authored kana when it differs from the target. Show both aids after revealing a recognition card. Shared study playback uses a named speaker icon that changes to a stop icon during playback.

Derive romaji in the learner from the existing authored kana. This makes vocabulary pronunciation available offline and gives edited notebook readings the same treatment. Use familiar kana-to-Latin correspondences and explicitly space common phrases. Handle context-dependent spellings such as the final `wa` in `konnichiwa` as complete vocabulary phrases. Retain kana vowel sequences for study and double the preceding vowel for the katakana long-vowel mark. [Japanese Agency for Cultural Affairs romanization guidance](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/roma/index2.html)

This guide covers vocabulary entries. Sentence examples and dialogues continue to use authored kana because particle pronunciation and word boundaries depend on context. A personal note can show romaji when its saved kana reading can be converted. Examples of rhythmic and pitch-accent detail belong in audio or separately authored material. Lesson identities and stored notebook values do not need a migration.
