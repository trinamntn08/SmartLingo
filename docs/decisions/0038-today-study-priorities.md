# ADR 0038 · Prioritise study actions on Today

Date: 2026-11-22

Status: implemented for local review

The owner flagged that the notebook occupied prime space despite being of limited use on this website. The earlier Today layout placed a short-lesson recommendation above a separate daily course. Owner review found that the two entry points made it unclear what to study next.

French Today now gives first priority to the guided day. Learn offers the same course entry and owns browsing, listening and speaking. Japanese keeps its kana-first recommendation and can reach the same daily course from Today and Learn. A shared course reader gives both screens the same saved section. The recommendation resumes the last unfinished day visited, advances to the first unfinished day after a completion, and offers revisiting after all available days are completed. Time away does not skip days.

Practice links connect the end of a French day to existing library lessons with a matching purpose. A validated study-day link returns to the originating section, including after reloading. Library attempts and guided course events keep their existing meanings and progress. Review remains the home for saved words. [Implementation](../plans/0048-unified-daily-learning-path.md) · [Curriculum rationale](../curriculum/daily-course-and-library.md)

The order reflects likely goals for a short language-learning visit. SmartLingo has no live navigation counts for these choices. Existing learning events record only some forms of study, and listening and guided speaking do not write comparable events. Those counts cannot establish a ranking of what users want to open.

For the first learner trial, show Today to both new and returning learners in each language. Ask them to describe what they came to do and let them make their first choice unprompted. Record the stated goal, first click, whether they reached the intended activity and any hesitation. Measure repeat learners separately from first-time visits. Use the observed goals and navigation misses to revisit the order. This layout adds no analytics collection.
