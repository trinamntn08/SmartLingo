# 0043 Everyday French and slang reference

Date 2026-11-24. Accepted for the local learner preview. The language content and generated scenes await owner review.

The French learner opens Slang from the main navigation or `/slang/fr`. The same screen supports situation filters and French or English search across 287 expressions in 12 categories. Bilingual examples, usage notes, and informal, slang or vulgar register labels appear directly on the cards. Verlan entries name the source words. Text shorthand is labelled separately.

The reference has stable content IDs and saves through the existing French notebook, including the two source IDs already shared with the French curriculum. Browsing and saving have no lesson completion events. Spoken expressions use the existing French audio control. The routed catalogue keeps temporary filter and pagination state within a browser visit. The preview server and offline worker recognise its URL. ## Language references from the Cloud draft

- The three learner-facing register labels were informed by [Le Robert’s guide to registers](https://dictionnaire.lerobert.com/guide/registres-de-langue).
- The original authors checked individual senses and registers. [Pote](https://dictionnaire.lerobert.com/definition/pote) · [Daron](https://dictionnaire.lerobert.com/definition/daron) · [Taf](https://dictionnaire.lerobert.com/definition/taf) · [Boulot](https://www.larousse.fr/dictionnaires/francais/boulot/10578) · [Galère](https://www.larousse.fr/dictionnaires/francais/gal%C3%A8re/35874)
- Verlan forms were checked against dictionary entries and descriptions of the process. [Relou](https://www.larousse.fr/dictionnaires/francais/relou/67916) · [Chelou](https://dictionnaire.lerobert.com/definition/chelou) · [Larousse on verlan](https://www.larousse.fr/dictionnaires/francais/verlan/81556) · [Rutgers French Magazine introduction](https://sites.rutgers.edu/french-magazine/introduction-au-verlan/)
- A teaching guide cross-checked texting abbreviations. [Accent Français SMS guide](https://www.accentfrancais.com/fr/blog/langage-sms-francais)

The French examples, English glosses and notes were authored for SmartLingo. The catalogue has no measured frequency ranking.
