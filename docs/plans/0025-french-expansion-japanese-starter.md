# French topic expansion and Japanese starter

Status: completed
Owner: primary agent

## Outcome

Add French banks for cycling and household waste, with five short lessons and 30 distinct targets in each. Learners can switch to a bundled Japanese starter course and use the same Today, Explore, Practice, lesson, notebook and review screens. French stays the default for existing learners. English study explanations remain visible in both courses.

## Steps and ownership

- Primary agent owns the domain contracts, French topic banks, bundled Japanese starter content, catalogue order, and repository integration.
- UI builder owns the course selector and shared learner journeys, course-scoped views, audio presentation, and Japanese browser coverage. French curriculum editing and optional provider features remain available in the French course.
- Use separate Japanese content IDs, optional kana readings and existing browser persistence. Existing French lesson revisions and IDs are preserved. New lessons are draft previews.

## Validation

Check curriculum and bank counts, canonical IDs, existing French payloads, sentence solvability and Japanese search. Exercise switching courses and opening a Japanese lesson in wide and narrow Chromium and run repository, application, and relevant browser checks. Use fake device voices for browser audio checks.

## Handoff

The French and Japanese lessons are ready for owner review in the learner preview. The French drafts follow the existing curriculum workshop workflow. See the [checkpoint](../SESSION_CHECKPOINT.md) for browser, offline and application test results.
