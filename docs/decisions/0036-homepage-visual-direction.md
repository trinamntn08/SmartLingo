# 0036. Homepage photos guide new SmartLingo visuals

Accepted 2026-11-22.

The owner selected the existing French and Japanese homepage photos as the basis for an ongoing image, photo and icon workflow. The shared concept is everyday places where adults use the language, with candid editorial photography, natural daylight, warm neutral materials and restrained accents. Illustrations use simple, recognisable shapes and the same colour cues. Functional icons use the existing line family for clarity at control sizes.

The [visual asset skill](../../.agents/skills/sll-create-visuals/SKILL.md) and [visual asset agent](../../.codex/agents/visual-asset-maker.toml) use both source photos as references. Visual checks cover responsive cropping, cultural and vocabulary accuracy, accessibility and provenance. Existing presentation scenes and language-specific word bindings retain their separate roles.
