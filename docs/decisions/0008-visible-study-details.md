# ADR 0008: Display study support directly

Date: 2026-11-14
Status: accepted — explicit owner preference

The owner requested that meanings, examples and explanations be visible without opening dropdowns. This replaces the earlier optional-reveal default for study material.

Vocabulary cards show French, meaning, example with translation and a labelled explanation together. Dialogue translations and grammar are also visible directly. Saved notebook meanings appear alongside the saved word/example. The shared lesson component gives editor previews the same presentation. Remove the unused generic study reveal control.

Recall cards and exercise hints remain deliberate practice controls; this change does not modify rating rules, answer checking, curriculum revisions, stored progress or personal entries. The layout keeps the existing cream palette, illustration, audio, save and next actions, with fewer controls and clear text grouping. Narrow screens place a small illustration beside the word so a large picture does not precede the study details. Verify desktop and narrow browser layouts; long content can still require scrolling.
