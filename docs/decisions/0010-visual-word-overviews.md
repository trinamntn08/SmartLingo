# 0010 — Direct topics and visual vocabulary overviews

Date: 2026-11-14. Status: accepted for implementation.

The owner requests a topic list on the right of the web view, rapid access to words without serial Next controls, and drawings/photos for new vocabulary. Use an always-available right pane on wide screens and a horizontally scrollable topic strip on narrow screens. Keep it outside the main content scroll area so choosing another topic remains available during practice. App owns selection; topic changes clear stale search/level filters. Words appear before optional lessons.

Owner correction later on 2026-11-14 supersedes the side placement above: topics belong on the left. Move the desktop pane before the content and its divider to the right edge; keep the phone strip. Both headers use a shared keyboard-accessible SmartLingo home control. Home closes the editor view and resets learner navigation to Today without unmounting the editor or discarding unsaved fields. Existing Return to learning behaviour remains available.

Reuse one VocabularyCard for topic banks and six-word lesson overviews. Show target, meaning, example, translation and explanation together, with Listen and atomic notebook capture. No per-word progression is necessary. A deliberate Continue to dialogue action records review of the displayed set with a vocabulary viewed event whose itemId equals lesson.id. Domain progress expands it only within the matching lesson/revision. Existing per-entry viewed events and backup/event formats remain compatible. Opening a grid alone creates no study event; completion and matching/sentence results remain separate deliberate actions.

Keep original SVG assets and stable-ID/target associations in a separate typed content media catalogue. A vocabulary edit invalidates a new visual association if its target changes, rather than silently attaching an obsolete image. The learner renderer consumes this catalogue through a small WordIllustration component and retains legacy concrete pictures. Unknown/abstract words remain text-supported. These are contextual learning aids, not a replacement for explicit meaning matching. Do not change published or locally edited curriculum payloads to add presentation assets, and do not infer owner media approval from generation. No storage migration, remote media requests or new dependency is needed.
