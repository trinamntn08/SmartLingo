# 0037. Generate SmartLingo website images and photos

Accepted 2026-11-22. The owner requires new SmartLingo website pictures, photos and illustrations to be generated with models approved for the project. The rule applies to the learner and editor, including the French daily course, its covers and its vocabulary cards.

Generate from original written briefs. An existing SmartLingo-generated image can be reused or supplied as a style reference when its record confirms the input and usage rights. External images are excluded, including stock, licensed or public-domain images, scans, screenshots, downloaded images, and third-party uploads. This covers copying, tracing, editing, compositing, hotlinking, and prompting from an external image. The repository's design references may guide interface design. Use the two internally generated homepage photos as the image-generation style anchors. Existing functional UI icons remain part of the code-drawn icon system.

Prompts describe generic people, settings, objects and actions. Avoid requests to recreate identifiable people, specific artwork, copyrighted characters, covers, logos, branded packaging or a named artist's work. Check the selected model's output terms for the planned website and offline uses. Record the prompt, model, source of each permitted reference, output and edits, review and release status. Inspect the actual output for recognisable third-party elements, suspicious resemblance and misleading visual details. Reject questionable outputs and use a newly generated candidate or an accessible text presentation. The fact that a model produced an image does not establish that the image is clear to use.

The owner extended this rule to all app photography on 2026-11-22. Retire legacy external photos and the in-app photo credits from new versions. Preserve provenance and required attribution for older distributed copies in the historical inventory. Use approved SmartLingo-generated photos or the existing illustration or text fallback across lessons, topics and review.

The [media source guide](../MEDIA_SOURCES.md#generated-image-workflow) defines the review record and [the French daily-course plan](../plans/0043-french-daily-course.md) defines the delivery checks.
