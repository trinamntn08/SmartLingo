# 0051 · Learner sidebar navigation

Accepted on 2026-11-28, Europe/Paris.

Today combines the topic library and guided course choices under **Find lessons**. **Practise a skill** links to the existing listening and speaking destinations. The full library replaces the sample topics as the first link in both languages. Japanese Foundations remain in that library.

The course outline presents the open course and recorded completion, with the current unit expanded and other units discoverable by title and count. A level filter opens matching units and keeps their counts in context. The two links below the outline open the full topic library and the **Guided courses** section of Today. The course link uses the existing Today path with a copyable section query and focuses the course heading on arrival.

The desktop and compact surfaces share the sidebar row and use visit-local disclosure state. Course, topic and progress identifiers remain those of the existing learner. This updates the navigation groups in [0047](0047-today-study-navigation.md). [Execution plan](../plans/0068-learner-sidebar-navigation.md)

The owner requested unit-only browsing for the Japanese guided course. Its learner header and course card omit the draft-preview label. The curriculum retains its draft status and review information.
