# 0046 · Study notebook interface

Accepted on 2026-11-27, Europe/Paris.

Use the owner’s cream-and-yellow references to give the bilingual web learner the character of a study notebook. Use a warm paper palette and near-white surfaces, keep the SmartLingo mark, and reserve yellow for the lead action and the narrow current-page marker. A system serif is used for the English entry headings. Bundled Inter remains the interface face, with the existing Japanese fallbacks.

Use the existing generated street scenes on the chooser and Today. Let bilingual transcripts, vocabulary photographs, characters and practice carry the visual emphasis during study. Group related actions and information with ruled rows and spacing.

The established lesson routes, curricula, progress scopes, audio controls and offline cache behavior are the implementation contracts for this pass. Adapt the material-first Cloud presentation where it fits those contracts. Its separately developed Japanese curriculum, recordings and Android packaging have their own rollout histories.
