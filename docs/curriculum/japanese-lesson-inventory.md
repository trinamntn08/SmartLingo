# Complete Japanese lesson inventory

This inventory reflects the bundled draft content and stable runtime identifiers. See the [curriculum map and audit](japanese-curriculum-redesign.md).

The baseline contained 20 kana rows, 13 guided lessons and 69 topic lessons. The revised catalog has 53 kana lessons and retains all 82 guided and topic lesson identifiers. Guided and library study have separate progress.
