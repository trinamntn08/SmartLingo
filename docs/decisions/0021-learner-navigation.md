# ADR 0021: Responsive learner navigation

Date: 2026-11-22
Status: accepted for the local learner preview

## Context

The permanent narrow topic strip and wrapping tabs occupied much of a phone screen. Opening the next lesson stage could leave the scroll position at the bottom of the preceding activity. The owner’s browsing requirements call for free access to the topic list, a persistent desktop rail, a horizontal phone list and vocabulary above optional lessons.

## Decision

Keep the topic rail on desktop. Put the same horizontal topic list behind a Topics control in the narrow header and make the five primary destinations available in a bottom bar. Keyboard users can skip directly to content or narrow navigation. Keep the word bank above the lesson list and provide a direct shortcut down to the lessons. Focus each new activity heading when advancing a lesson on web.

## Consequences

The Today screen highlights a starter or returning lesson using saved events and the existing catalogue. The hero artwork is an original fictional neighbourhood scene generated for SmartLingo with OpenAI ImageGen and ships as a local JPEG in the existing offline export. Existing vocabulary photos retain their individual credits. Lesson revisions, notebook data, recognition ratings and audio use the existing contracts.
