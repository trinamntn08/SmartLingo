# Bundled vocabulary photographs: sources and rights

Created 2026-11-15 for the local learner preview. This catalogue is separate from lesson revisions and publication. Adding a photograph does not approve the French curriculum or claim that a learner has mastered a word.

The reviewed batch contains 120 local photographs: 116 from Wikimedia Commons and four from Pexels. They serve 397 of 705 current exact vocabulary ID/target pairs (116 literal and 281 explicitly contextual), with 308 gaps listed in the coverage inventory. The JPEG files total 7,802,322 bytes. Commons metadata comes from its official [image information API](https://www.mediawiki.org/wiki/API:Imageinfo); the four Pexels contributors and free-use status were checked on their individual photo pages. Each accepted file has its own source page, creator, licence and licence URL, retrieval date, resize disclosure, exact local filename, byte count and SHA256 in `apps/learner/public/vocabulary-photos/sources.json`. The same information is presented in the bundled [photo credits page](../apps/learner/public/vocabulary-photos/credits.html). No API key, paid call, remote image hotlink or ordinary playback/download request to either source is required during learning.

Commons does not supply one blanket licence: [its reuse guide](https://commons.wikimedia.org/wiki/Commons:Simple_media_reuse_guide) requires checking each individual file. Commons files in this collection use public-domain/CC0, CC BY or CC BY-SA rights. Attribution and licence links remain available next to each image in the local credits page and in the source manifest. For CC BY-SA images, the redistributed resized JPEG remains available under its recorded CC BY-SA licence. The app's original code and curriculum are separate works. See [Commons licensing guidance](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/licenses) and [Creative Commons attribution guidance](https://creativecommons.org/reusing-cc-licensed-content/).

The four Pexels photographs use the separately identified [Pexels License](https://www.pexels.com/license/), which permits free commercial and noncommercial use within a creative work. They are not claimed to be CC0 or public domain. The collection credits Towfiqu barbhuiya (calendar), Mikhail Nilov (paperwork), Cedric Fauntleroy (clinic conversation) and RDNE Stock project (adult classroom). These are vocabulary context scenes, without endorsement or claims about the subjects' actual health, abilities or identities. Standalone resale/stock redistribution is not the purpose of this learner app; preserve the licence terms when reusing the files.

The local JPEG files are Wikimedia- or Pexels-generated thumbnails, normally around 480–500 pixels wide. They are not cropped, retouched, recoloured, watermarked or composited by SmartLingo. The source record discloses the resize. Thumbnail bytes are bounded before writing and verified by SHA256; Chromium decoding checks actual image dimensions. Source metadata is retained as data. HTML credits escape text and attributes; source links require HTTPS on the known Commons/Pexels hosts, and licence links require HTTP(S) on the known Commons/Creative Commons/Pexels hosts. Provider HTML is never injected into the app.

`packages/content/src/photos.ts` exposes `getVocabularyPhoto(id, target)`. Bindings require both the exact stable vocabulary ID and the exact reviewed French target. A changed target, unknown personal word or JavaScript inherited-property name receives no photograph. Current alternative target forms on one canonical ID have separate bindings. Literal photos depict the actual object or action. Context photos begin “Context photograph:” and describe a plausible visible task setting; they do not claim that a stock subject has an allergy, a particular relationship, an intention, an occupation or a medical condition. The visible French/English meanings and examples remain essential.

The [coverage inventory](PHOTO_COVERAGE.md) lists every current ID/target pair, including all remaining gaps. A bounded contact-sheet review checks whether each accepted photo is recognisable and its binding is defensible. It cannot establish owner approval, linguistic teaching quality, model releases, or accessibility quality on all devices. Unsuitable drawings, museum sketches, micrographs and merely incidental objects returned by automatic searches are rejected. Known gaps retain the learner's existing drawing/text fallback.

An independent review recovered the blue shirt's creator, ChristianGlaeser, from its original Commons file page/history after incomplete API metadata omitted the name. That actual creator credit is preserved rather than replaced by an unknown-author placeholder. A photographed ancient ritual bowl was removed from the cooking catalogue because its sculpted contents made it unsuitable as an ordinary kitchen bowl; its image is not shipped.

Maintenance is deliberate: `node --import tsx scripts/collect-vocabulary-photos.mjs` collects proposed Commons sources; `collect-stock-photos.mjs` contains the four individually verified Pexels fallbacks. `node --import tsx scripts/review-vocabulary-photos.mjs` decodes the files and creates contact sheets. `curate-vocabulary-photos.mjs` records the bounded review's rejected matches, descriptive captions, literal/context distinctions and related task associations; its explicit `--approve` option records byte-specific visual approval after checking refreshed sheets. The review script's `--generate` option refuses absent/stale visual approvals and writes the lookup, source manifest, escaped credits page and complete coverage inventory. Collection is not part of builds, hooks, tests or runtime. Review the files and bindings before generation, preserve the recorded rights, and remove review contact sheets before committing. Source rate limits stop collection without claiming that missing files were fetched. No full photo coverage is claimed.
