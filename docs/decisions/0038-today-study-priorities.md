# ADR 0038 · Prioritise study actions on Today

Date: 2026-11-22

Status: implemented for local review

The owner flagged that the notebook occupied prime space despite being of limited use on this website. Today now gives first priority to starting or resuming a recommendation. The guided daily course follows as the option for structured study. The remaining shortcuts let learners browse vocabulary and lessons, listen to sentences or find videos, and speak through a dialogue. Learners can find and edit saved words in Review.

The order reflects likely goals for a short language-learning visit. SmartLingo has no live navigation counts for these choices. Existing learning events record only some forms of study, and listening and guided speaking do not write comparable events. Those counts cannot establish a ranking of what users want to open.

For the first learner trial, show Today to both new and returning learners in each language. Ask them to describe what they came to do and let them make their first choice unprompted. Record the stated goal, first click, whether they reached the intended activity and any hesitation. Measure repeat learners separately from first-time visits. Use the observed goals and navigation misses to revisit the order. This layout adds no analytics collection.
